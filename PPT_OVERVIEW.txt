================================================================================
                        SLIDE 2: PROBLEM & SOLUTION
================================================================================

    THE PROBLEM
    ════════════
    
    ❌ Manual inventory tracking leads to errors
    ❌ Difficulty monitoring stock levels across locations
    ❌ No real-time visibility into low stock situations
    ❌ Inefficient order processing and management
    ❌ Lack of analytics for business decisions
    
    
    OUR SOLUTION
    ════════════
    
    ✅ Centralized digital inventory management platform
    ✅ Real-time stock tracking with automated alerts
    ✅ Low stock notifications to prevent stockouts
    ✅ Streamlined purchase and sales order processing
    ✅ Interactive dashboards with actionable insights
    ✅ Role-based access control for security


================================================================================
                        SLIDE 3: KEY FEATURES
================================================================================

    🔐 AUTHENTICATION & SECURITY
    ─────────────────────────────
    • JWT-based secure login
    • Role-based access (Admin, Manager, Employee)
    • Password encryption with bcryptjs
    
    
    📦 PRODUCT MANAGEMENT
    ─────────────────────
    • Full CRUD operations
    • SKU & barcode tracking
    • Min/Max stock level configuration
    • Category & supplier assignment
    • Expiry date tracking
    
    
    📋 ORDER MANAGEMENT
    ───────────────────
    • Purchase orders (stock increase)
    • Sales orders (stock decrease)
    • Multi-item orders with validation
    • Automatic stock adjustments
    • Order status tracking (Pending/Completed/Cancelled)
    
    
    📁 CATEGORY & SUPPLIER MANAGEMENT
    ─────────────────────────────────
    • Organize products into categories
    • Track supplier contact information
    • Link products to suppliers

                    SLIDE 5: TECHNICAL ARCHITECTURE
================================================================================

    SYSTEM ARCHITECTURE
    ═══════════════════
    
    ┌──────────────────────────────────────────────────────────────┐
    │                        FRONTEND                              │
    │   React 18 │ Material-UI │ React Router │ Recharts │ Axios  │
    └──────────────────────────┬───────────────────────────────────┘
                               │ REST API (HTTP/HTTPS)
                               ▼
    ┌──────────────────────────────────────────────────────────────┐
    │                        BACKEND                               │
    │         Node.js │ Express.js │ JWT │ bcryptjs                │
    └──────────────────────────┬───────────────────────────────────┘
                               │ Sequelize ORM
                               ▼
    ┌──────────────────────────────────────────────────────────────┐
    │                       DATABASE                               │
    │                      PostgreSQL                              │
    │   Users │ Products │ Categories │ Suppliers │ Orders        │
    └──────────────────────────────────────────────────────────────┘
    
    
    API ENDPOINTS
    ─────────────
    • POST /api/auth/login      - User authentication
    • POST /api/auth/register   - User registration
    • GET/POST/PUT/DELETE       - Products CRUD
    • GET/POST/PUT/DELETE       - Categories CRUD
    • GET/POST/PUT/DELETE       - Suppliers CRUD
    • GET/POST/PUT/DELETE       - Orders CRUD
    • GET /api/reports/*        - Reports & Analytics
    
    
    UI/UX FEATURES
    ──────────────
    • Responsive design (Mobile/Tablet/Desktop)
    • Command Palette (Ctrl+K) for quick navigation
    • Breadcrumb navigation
    • Toast notifications
    • Dark mode support (ready)
